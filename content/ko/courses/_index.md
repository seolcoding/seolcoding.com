# 공공기관 10년, AI로 7개 기관에서 강의 중

실무에서 직접 쓰는 AI 도구를 가르칩니다.
168개 콘텐츠를 자동화하고, 국가 기관 AI 프로젝트 6건을 수상한 개발자입니다.

---

## 강의 가능 주제

- **생성형 AI 기초** (Gemini / ChatGPT) — 시민·공무원·일반 직장인
- **프롬프트 핵심 기법 + 데이터 구조화** — 기업·공공기관 실무자
- **RAG 작동 원리 + 업무용 챗봇 구축** — 기술직·개발자
- **바이브 코딩 — AI로 웹앱 빠르게 만들기** — 비개발자 실무자
- **AI 에이전트 파이프라인 구축** — 개발자

## 직접 만들고 운영하는 AI 파이프라인

### 잼판툰 (jam_pan_toon)

법원 판결문을 읽기 쉬운 6컷 인스타그램 웹툰으로 자동 변환합니다.
어려운 법률 지식을 20~40대가 공감하는 이야기로 풀어내는 콘텐츠 자동화 프로젝트.

- **168개** 판결 사건 처리 완료
- PDF 판결문 입력 → 6컷 웹툰 스토리 + 캡션 → Instagram 자동 게시
- 3단계 LLM 검수로 품질 보장
